# Consignes du projet

- Pour chaque intervention modifiant le projet, créer d'abord une entrée datée dans `CHANGELOG.md` décrivant les changements prévus.
- Avant de terminer, compléter cette entrée avec les changements effectivement réalisés, les vérifications, leurs résultats et les limites éventuelles.
- Conserver les entrées précédentes et les modifications de l'utilisateur.
